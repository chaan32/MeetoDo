# 5단계 마감 알림 구현 계획

사용자 정책으로 승인 완료. LLM 없이 평일9시 Asia/Seoul, 기본 비활성, 주입 Clock, 날짜별 DB 유니크 선점 및 실패 자동 재시도 없음. 개발 API local만, force 명시 예외.

- [x] 미구현 수동 API 404와 회의 전용 생략 안내 문제의 RED 확인.
- [x] DailyDigest 날짜 유니크 행을 독립 트랜잭션에서 커밋하고 전송한다. 선점 실패는 외부 경계에서 ALREADY_SENT로 처리한다.
- [x] TODO 구간/담당자·미정 묶음/미정 상세 경고/마감 없음 개수를 구성한다.
- [x] 공통 NotificationMessage 유형과 기존 플랫폼 변환·전송을 재사용한다. OpenAI 없이 local 알림 빈을 허용한다.
- [x] 선택 스케줄과 local 수동 API, 날짜 입력 검증, force와 실패 상태를 구현한다.
- [x] 날짜 경계/기본비활성/프로필/중복·동시성/force/실패/JSON·길이·보안 테스트.
- [x] E 원값·D 평균 비교, README·DEVLOG·데모 문서 및 실제 검증 근거 기록.
- [x] 전체 ./gradlew test bootJar --no-daemon 및 실패/오류/건너뜀 집계.

실제 외부 전송·데이터 삭제·커밋은 하지 않는다. 공유 DB의 유니크 제약은 여러 인스턴스의 정상 실행 선점을 보호하지만, 현재 H2 파일 DB를 여러 서버가 공유하는 배포는 지원하지 않는다. force는 개발용 명시적 재전송으로 이 보호를 우회한다. 전송 직전/직후 프로세스 종료에 대한 정확히 한 번 전달은 보장하지 않는다.
