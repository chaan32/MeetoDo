# 성명 분리 E 구현 계획

승인한 설계: 성·이름 명시 저장, 전체 이름 계산, 공통 매칭(전체 이름 우선 → 이름 → 없을 때만 끝 호칭 님/씨 한 번 제거), 모델이 직급·조사를 제외한 이름 추출. 실제 멘션·B 정책·데이터 백필은 보류.

- [x] 기존 이름·호칭 조회 실패를 테스트로 먼저 확인한다.
- [x] Member familyName/givenName과 fullName, 새 개발 샘플을 구현한다. 성을 추측해 자르지 않는다.
- [x] 이름 조회/직접 API/findTasks/ID-이름 검증/팀 불일치 가드에 같은 매칭 규칙을 연결한다.
- [x] findMember 설명·파라미터·시스템 프롬프트에 모델 추출과 서버 매칭 책임을 명시한다.
- [x] 기존 테스트 fixture를 명시적 성·이름으로 전환하고, 전체 이름·호칭·두 글자 성·충돌 우선순위·팀 가드·D 스냅샷·알림을 검증한다.
- [x] README·DEVLOG·확인 문서에 역할 분담/한계/개발 데이터 초기화 안내와 빈 E 실측 열을 기록한다.
- [x] ./gradlew test bootJar --no-daemon 전체 결과를 집계한다.

데이터 삭제·커밋은 사용자가 한다. measure.sh 원문과 D 실측 원값은 변경하지 않는다. 매칭 결과가 같아도 후보/응답의 전체 이름이 바뀌므로 E는 별도 실험 조건이다.
