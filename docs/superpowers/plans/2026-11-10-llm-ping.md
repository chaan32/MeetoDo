# LLM Ping Implementation Plan

**Goal:** 사용자가 직접 키를 설정해 OpenAI 연결을 확인할 개발 전용 GET API를 만든다.

**Spec:** AGENTS.md 및 사용자의 이번 요청. 실제 유료 API 호출은 사용자가 수행한다.

**Design:** 컨트롤러의 `@Profile`과 YAML `spring.config.activate.on-profile`에 `local & openai & !test`를 적용한다. 기본 설정은 AI 비활성화다. 고정 프롬프트를 ChatClient로 보내고 nanoTime 차이를 ms로 반환한다. 공급자 예외 원문은 응답·로그에 노출하지 않는다.

- [x] 프로필별 빈·라우트·Swagger 노출과 mock 성공/실패 테스트를 먼저 작성하고 실패를 확인한다.
- [x] 개발 전용 컨트롤러와 프로필 설정을 구현한다.
- [x] 전체 테스트와 bootJar 빌드로 검증한다.
- [x] 실행 안내와 변경 파일·설계 질문을 정리하고 실제 연결 확인 전에 멈춘다.

**검증:** 기본/local/openai/test/test+openai/local+openai+test 및 순서 변경에서는 모델·라우트가 없어야 한다. local+openai를 모사한 테스트에서는 공급자 모델을 mock으로 교체한다. 응답 텍스트·시간·고정 프롬프트·캐시 금지·오류 원문 비노출을 검증한다.

**결과:** 구현 전 16개 중 7개 실패 → 구현 후 16개 모두 통과. `./gradlew test bootJar --no-daemon` 성공. 실제 공급자 호출 및 성능 측정은 미실행.
